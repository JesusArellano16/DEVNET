# DEVNET
This workspace is for the backup script project

Instructions below

For MAC users
    #Create a virtual environment
    - "python -m venv venv"
    
    #Install dependencies 
    -"pip install -r requirements.txt"

Create a .env file with the following structure
    USERS = "user"
    PSWDS = "password"

Run the project with 
    -"python main.py backup r9 site"
        *Site is the central one that is supported, like sotelo, etc.
